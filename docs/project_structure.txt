Sport Analytics — Project Structure
====================================
3x3 basketball tracking / analytics pipeline.

Run scripts from the project root so relative paths resolve correctly.


Mapping accuracy workflow (2D court map)
----------------------------------------
1) Refit calibration (no off-image clicks; optional wide-angle k1):
     python scripts/02_calibration/refit_official_homography.py --k1 -0.16
   Or click landmarks yourself (best next step if wireframe still drifts):
     python scripts/02_calibration/calibrate_court_interactive.py

2) Full reproject pipeline (feet + H + smooth + stills):
     python scripts/03_processing/run_mapping_pipeline.py --skip-refit

3) Visual checks:
     media/checks/official_calibration_checkv2.jpg
     media/checks/feet_check_frame_*.jpg
     python scripts/diagnostics/render_mapping_preview.py

4) Full diagnostic render (ball uses possession ground-proxy on map):
     python scripts/06_visualization/render_with_2dmap.py
